# ⚒️ C# Foundry

**A hands-on collection of C# fundamentals, coding exercises, and mini-projects.**

C# Foundry is a practical coding repository focused on building a strong foundation in C#. It contains small programs, concept-based implementations, problem-solving exercises, and experiments with core language features.

The repository is organized by topic, making it easy to revisit concepts, review implementations, and track progress as the codebase grows.

---

## 📂 What's Inside?

| Module | Contents |
|---|---|
| **Fundamentals** | Variables, data types, type conversion, constants, and operators |
| **Control Flow** | Conditional statements, switch expressions, loops, and logical conditions |
| **String Manipulation** | Formatting, interpolation, comparisons, iteration, and validation |
| **Arrays & Collections** | Arrays, sorting, reversing, lists, dictionaries, and basic data operations |
| **Methods** | Parameters, return values, optional arguments, named arguments, and references |
| **Error Handling** | Exceptions, `try-catch`, input validation, and custom parsing logic |
| **Debugging** | Identifying logic errors, inspecting variables, and tracing program execution |
| **Object-Oriented Programming** | Structures, classes, fields, properties, methods, and `ToString()` overrides |
| **Practice Exercises** | Small standalone problems that combine multiple language concepts |
| **Mini-Projects** | Compact console applications built by applying concepts in practice |

---

## 🧪 Exercises & Implementations

The repository includes practical implementations such as:

- Odd/even number checker
- Multiplication table generator
- FizzBuzz
- String reversal
- Password checker
- Odd/even number separation
- Array of multiples
- Triangle area calculator
- Sum of array elements
- Custom `TryParse` implementation
- Logic-error debugging exercises

Each exercise is intended to practise a specific programming concept and develop the ability to translate a problem into working code.

## 🎯 Purpose

This repository serves as a practical reference for:

- Strengthening C# syntax and core programming concepts.
- Practising problem-solving through small, focused exercises.
- Understanding how language features behave through implementation.
- Experimenting with different approaches to the same problem.
- Building a foundation for more advanced C# and .NET development.

The emphasis is on **working code, practical understanding, and consistent improvement** rather than collecting examples without understanding them.
